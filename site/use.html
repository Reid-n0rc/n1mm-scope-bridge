Using the window

N1MM Scope Bridge opens its window when it starts. These pictures are taken automatically from the program itself, using the current development version for version {{version}}.

Streaming to N1MM+

Choose your radio and how to reach N1MM+, then select Start. Settings are saved automatically. While streaming, the Status panel shows the radio's frequency, span, and scope mode, and how many updates per second go to N1MM+.

No radio connected? Turn on Use the built-in emulator to try the bridge and set up N1MM+ first.

The controls

ControlWhat it does
RadioYour radio model.
Use the built-in emulatorStreams a simulated FT-710, so you can try the bridge or set up N1MM+ without the radio.
FTDI library folderThe folder with FTDI's LibFT4222-64.dll. Leave it empty if setup copied the library for you.
Source nameThe name you pick in N1MM+'s Spectrum Display settings. It's the radio model unless you change it.
N1MM+ PC and Port127.0.0.1 and 13064 when N1MM+ runs on this PC.
UpdatesUpdates per second sent to N1MM+ (default 4, at most 10).
DisplayLatest, Average (smoother), or Peak hold (keeps short signals visible).
ScalingHow the radio's levels map to dB in N1MM+. Leave the default unless the display looks too strong or weak.

A problem with a value is shown right under the field. The radio and N1MM+ settings lock while streaming; press Stop to change them.

The status panel

The Status section updates several times a second: whether the radio is sending, the VFO, span and scope mode, updates per second sent to N1MM+, dropped or bad frames, and the last error. Outside Center mode it reminds you to set Center for exact frequencies. The Log keeps the last 500 messages.

Closing and the system tray

The bridge keeps streaming while it runs in the system tray. When you close the window it asks whether to keep running in the tray or exit. Tick Remember my choice to stop asking. Minimizing also sends it to the tray. Right-click the tray icon to show the window, start or stop streaming, or exit.

When something is wrong

Problems are shown in plain words with what to do next. For example, if FTDI's library for the FT-710 is not installed, the bridge links to FTDI's download page.

Use Copy diagnostics in the Log section when you report a problem. Your Windows account name is removed from it.
