Frequently asked questions

The bridge says it can't find the radio's scope (Could not open 'FT4222 A')

On the FT-710, open the menu OPERATION SETTING → GENERAL → SCU-LAN10 and set it to ON. You don't need the SCU-LAN10 adapter: this setting is what makes the radio send its scope over USB. After changing it, turn the radio off and on and unplug and replug the USB cable (a power cycle alone isn't enough), then press Start again. Also check that the radio is on, the USB cable is connected, FTDI's LibFT4222 is installed, and no other program (such as wfview) is using the scope.

Does the bridge conflict with N1MM+'s CAT connection?

No. The bridge never opens the radio's COM ports, so N1MM+ keeps full control of the radio for CAT and keying.

Can the bridge transmit or change my radio's settings?

No. It only reads the scope data. It never keys the radio and never changes its settings.

Which radios are supported?

The Yaesu FT-710 is the first supported radio. Other Yaesu models with a built-in scope are planned. See supported radios.

Can I try it without the radio?

Yes. Turn on Use the built-in emulator in the window. It streams a simulated FT-710 so you can set up N1MM+'s Spectrum Display before connecting the radio.

Why does it ask for Center scope mode?

N1MM+'s frequency scale is exact only when the radio's scope is centred on the VFO. In Cursor or Fixed mode the bridge still streams, but the frequencies are approximate, so it shows a reminder. See Center scope mode.

Will it slow down N1MM+?

No. The bridge sends N1MM+ four updates a second by default (at most ten), as the N1MM+ team recommends. The radio is read on its own thread, so the window stays responsive.

Can I use it with two radios (SO2R)?

N1MM+ can show the bridge's spectrum for Radio 1 or Radio 2. Reading two FT-710s at once from one bridge isn't supported yet.

N1MM+ runs on another PC. Does that work?

Yes. Set N1MM+ PC to that PC's address and allow UDP port 13064 through its firewall. See N1MM+ on another PC.

Why does setup download FTDI's library separately?

The bridge reads the FT-710's scope with FTDI's LibFT4222 library (see Install). Its license doesn't allow it to be included inside this GPL-licensed program, so setup downloads FTDI's signed files for you during install (the option is on by default) and checks them before copying. If you install without internet, untick the option and download LibFT4222 from FTDI yourself.

Windows warns that the installer is unrecognised. Is it safe?

The installer isn't code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Choose More info, check the publisher and file name, then Run anyway. Each release lists SHA-256 checksums so you can confirm the download is genuine.

How do I uninstall?

Use Settings → Apps in Windows, or Uninstall N1MM Scope Bridge in the Start menu. Your settings are kept unless you choose to remove them.

Where do I get help?

Check Troubleshooting first. Then open an issue on GitHub and paste the text from Copy diagnostics in the window's Log section.
