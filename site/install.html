Install

What you need

  • Windows 10 or 11 (64-bit), the PC that runs N1MM Logger+
  • A Yaesu FT-710 connected by USB
  • FTDI's LibFT4222 library, from FTDI's website. It's free, but its license doesn't let us include it with this GPL program, so you install it yourself.
  • N1MM Logger+

Download

There is no release yet. When there is, an installer will be available here. Until then you can follow progress, or try the development version from source, on GitHub.
