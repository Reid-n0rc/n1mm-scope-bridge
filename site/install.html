Install

What you need

  • Windows 10 or 11 (64-bit), the PC that runs N1MM Logger+
  • A supported Yaesu radio (see supported radios)
  • N1MM Logger+

Yaesu FT-710

  • Connect the radio to the PC with a USB cable.
  • On the radio, set OPERATION SETTING → GENERAL → SCU-LAN10 to ON. You don't need the SCU-LAN10 adapter: this setting is what makes the radio send its scope over USB. With it OFF, the scope interface doesn't appear on the PC at all.
  • Install FTDI's LibFT4222 library from FTDI's website. The FT-710 sends its scope through an FTDI FT4222 chip, and this library reads it. It's free, but its license doesn't let us include it with this GPL program, so you install it yourself.

Setup steps for other Yaesu models will be added here as they become supported.

The setup wizard

Setup installs into your own user folder, so it doesn't need administrator rights. It shows the GPL license, offers a desktop shortcut and an option to start with Windows, and asks where you unzipped FTDI's LibFT4222 (you can skip that and set it later in the app).

If Windows warns about the installer

The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Choose More info, then Run anyway. Each release lists SHA-256 checksums so you can check the download.

First launch

  1. Start N1MM Scope Bridge from the Start menu (or let setup start it).
  2. Choose your radio. If you didn't let setup copy LibFT4222, set FTDI library folder to the folder you unzipped.
  3. Press Start. The status changes to Streaming and shows your radio's frequency and span.
  4. No radio connected yet? Turn on Use the built-in emulator to try everything first.
