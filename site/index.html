Your FT-710's waterfall, in N1MM Logger+

N1MM Scope Bridge reads the Yaesu FT-710's spectrum scope over USB and shows it in N1MM Logger+'s Spectrum Display window, the same way Icom radios work today.

Download {{version}} for Windows

Follow development on GitHub

How it works

  1. The radio streams its scope. The FT-710's USB port carries the spectrum scope on its own channel, next to the usual CAT ports.
  2. The bridge reads it. N1MM Scope Bridge reads that stream on your station PC.
  3. N1MM+ draws it. The bridge sends each spectrum line to N1MM+'s Spectrum Display, which you set to show it.

N1MM+ keeps full CAT control of the radio. The bridge never uses the CAT port and never transmits.
