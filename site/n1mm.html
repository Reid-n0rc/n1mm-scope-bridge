Set up N1MM+

Do this once. N1MM+ remembers it.

  1. Keep N1MM+ connected to the radio for CAT as usual (Config → Configure Ports). The bridge doesn't use the CAT port.
  2. Start N1MM Scope Bridge first, so N1MM+ can see its source name. By default the name is the radio model, for example FT-710.
  3. In N1MM+, open Window → Spectrum Display.
  4. Click the gear icon. In Spectrum Source, choose For all other radios, source named, then pick the bridge's name in External Source Name.
  5. For SO2R, choose Radio 1 or Radio 2 in General Options to match the radio the bridge is reading.

The bridge sends the frequency range and level scaling with every update, so there is nothing else to set in N1MM+.

On the radio

Yaesu FT-710

Set the scope to Center mode. Frequencies in N1MM+ are exact in Center mode. The bridge warns you if the scope is in another mode.

Settings for other Yaesu models will be added here as they become supported.

N1MM+ on another PC

N1MM+ listens on UDP port 13064. Point the bridge at that PC's address and allow UDP port 13064 through that PC's firewall.

Source: the N1MM+ manual, The Spectrum Display Window.
