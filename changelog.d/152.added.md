Installer: optional "Install FTDI USB driver (needs administrator)" task, offered only when Windows has no FTDI driver. It installs FTDI's Microsoft-signed WHQL driver package from Microsoft Update Catalog after checking its checksum, its Microsoft signature and that it covers the FT4222H. The app's "Could not open 'FT4222 A'" error now says when Windows sees the scope chip but has no driver for it. A daily GitHub check download-verifies and test-installs the pinned driver package, and reports whether ftdichip.com (which blocks automated downloads) has become usable.
