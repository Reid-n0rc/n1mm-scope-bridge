One installer for all Windows PCs: `n1mm-scope-bridge-setup-<version>.exe` now holds the x64 app, a native ARM64 app (Windows on ARM, including Windows 11 in Parallels on Apple silicon Macs) and a 32-bit command-line app, and installs the right one for the PC. On Windows on ARM it installs the x64 app by default, so FTDI's library can still be downloaded, and offers the native ARM64 app as an option. 32-bit Windows gets the command-line version with a Start menu shortcut, **N1MM Scope Bridge (command line)**, and setup downloads FTDI's 32-bit DLLs for it. Releases also include portable zips for each processor: `-win64`, `-winarm64` and `-win32`.
